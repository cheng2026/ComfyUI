                      ComfyUI - Quick Start Guide

PROBLEM SOLVED: Encoding issues and startup failures have been fixed.

CPU-ONLY MODE: ComfyUI is configured to use CPU only (no GPU detection).

================================================================================
READY TO START
================================================================================

1. SIMPLEST METHOD (Double-click):
   Navigate to: E:\ComfyUI
   Double-click: run_comfyui.bat
   Wait for console window
   Open browser: http://127.0.0.1:8188

2. POWERSHELL METHOD (Better error handling):
   Open PowerShell (right-click, Run as Administrator)
   Run:
     Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force
     cd E:\ComfyUI
     .\run_comfyui.ps1
   Open browser: http://127.0.0.1:8188

3. DIFFERENT PORT (using PowerShell):
   .\run_comfyui.ps1 -Port 8189
   Open browser: http://127.0.0.1:8189

4. SKIP DEPENDENCY CHECK (for faster subsequent startup):
   .\run_comfyui.ps1 -SkipDependencies

5. Check startup_error.log for detailed info

================================================================================
Important: CPU-Only Mode
================================================================================

ComfyUI is running in CPU-ONLY mode. This means:

  - NO GPU/CUDA will be used for local computation
  - NO automatic GPU detection
  - CPU is used for local operations only
  - Designed for API-based workflows (OpenAI, etc.)

This configuration is optimized for:
  ✓ Using official model APIs (remote computation)
  ✓ Workflow coordination without local GPU
  ✓ API-first architectures

For more details, read: CPU_MODE.txt
