================================================================================
                   ComfyUI CPU-Only Mode Configuration
================================================================================

All startup scripts have been configured to use CPU-only mode.

================================================================================
CPU-ONLY MODE SETUP
================================================================================

The following parameter has been added to all startup scripts:

    --cpu    (Force CPU-only computation)

This parameter ensures ComfyUI will NOT:
  - Detect CUDA/GPU devices
  - Attempt to load GPU models locally
  - Switch to GPU mode automatically

ComfyUI will use CPU exclusively for local operations.

================================================================================
WHAT CPU MODE IS FOR
================================================================================

CPU mode is typically used for:

1. **Using Official Model APIs**
   - OpenAI API (GPT, DALL-E, etc.)
   - Anthropic Claude API
   - Other cloud-based AI service APIs
   - These run on remote servers, not locally

2. **Testing and Debugging**
   - Testing workflows without GPU requirements
   - Integration testing with API services
   - Debugging node configurations

3. **API-First Architecture**
   - Local CPU handles workflow coordination
   - Remote API services handle heavy computation
   - Network bandwidth is the limiting factor, not GPU

================================================================================
WHY YOU MIGHT USE CPU MODE
================================================================================

NOT for local GPU-intensive tasks. Use it when:

  ✓ You're using remote APIs (OpenAI, etc.) - GPU locally doesn't matter
  ✓ You're testing workflows - API calls run on remote servers
  ✓ You want to avoid GPU memory overhead - for API coordination only
  ✓ You're running on a machine without a GPU - and using APIs

NOT for:

  ✗ Running large local models without GPU
  ✗ Image generation with local diffusion models
  ✗ Performance-critical local inference

================================================================================
ENVIRONMENT VARIABLES (Optional, for extra assurance)
================================================================================

If you want additional assurance that GPU is disabled, set these environment
variables before starting ComfyUI:

CUDA_VISIBLE_DEVICES=""
  Hides all CUDA devices from PyTorch

FORCE_CPU=1
  Forces CPU mode (if supported by the application)


Setting environment variables:

Command Prompt:
  set CUDA_VISIBLE_DEVICES=
  set FORCE_CPU=1
  run_comfyui.bat

PowerShell:
  $env:CUDA_VISIBLE_DEVICES = ""
  $env:FORCE_CPU = "1"
  .\run_comfyui.ps1


================================================================================
VERIFY CPU-ONLY MODE
================================================================================

When ComfyUI starts, look for these messages in the console:

Expected output (CPU mode):
  Device: cpu
  pytorch version: 2.x.x+cpu

NOT CPU mode (will NOT appear):
  CUDA available: True
  Device: cuda

If you see "Device: cpu", then CPU-only mode is working correctly.


================================================================================
PERFORMANCE AND SPEED
================================================================================

Performance depends on WHAT you're doing:

WITH REMOTE APIs (OpenAI, etc.):
  - Speed depends on API response time, NOT local CPU
  - Local CPU is only used for workflow coordination
  - Network latency is the primary factor
  - GPU locally makes NO difference

WITH LOCAL MODELS:
  - NOT recommended in CPU-only mode
  - Local inference would be very slow
  - But this is NOT the intended use case for CPU mode

CPU mode is optimized for API-first workflows where computation
happens on remote servers, not locally.


================================================================================
TROUBLESHOOTING CPU-ONLY MODE
================================================================================

If ComfyUI still tries to use GPU:

1. Check console output for error messages
2. Verify --cpu flag is in your startup command
3. Set CUDA_VISIBLE_DEVICES="" environment variable
4. Manually specify CPU in requirements (may need reinstall)

Manual PyTorch CPU reinstall:
  pip uninstall torch -y
  pip install torch --index-url https://download.pytorch.org/whl/cpu

================================================================================
FAQ: CPU-ONLY MODE
================================================================================

Q: Is CPU mode slow?
A: Depends on what you're doing. With remote APIs, speed depends on API
   response time, not local CPU. For local model inference, yes it's slow.

Q: Can I use this with OpenAI API?
A: Yes, CPU mode is perfect for API-based workflows.

Q: Can I use this with local models?
A: Technically yes, but not recommended. CPU mode is for API coordination.

Q: Will the --cpu flag cause errors?
A: No, it's a standard ComfyUI option and will not cause any errors.

Q: Can I switch back to GPU mode?
A: Yes, remove the --cpu flag from the startup script and restart.

Q: How do I verify it's using CPU?
A: Look for "Device: cpu" in the startup messages. Check console output.

Q: Why use CPU mode if not for local inference?
A: To avoid GPU detection overhead when using remote APIs, or to run
   on systems without GPU but with API access.

Q: Can I use GPU again later?
A: Yes, just use run_comfyui.bat without modifications or remove --cpu flag.
